# 심화 요구 사항 구현 시 기존과 변화한 것

## **1. 할인에 대한 이력 테이블 추가**

- applied_discount라고 하는 테이블을 추가했습니다.
- payment 테이블과는 다대일 관계입니다.
- 기존 할인와 관계 있는 테이블들에서 id를 제외한 모든 속성들을 가진 이력 테이블입니다.

## **2. 할인가 계산 로직 변경, 결제 리포지토리 기능 추가**

- 결제 전 최종 결제가를 계산하는 로직은 원래 최종 할인가만 리턴했습니다.
- 하지만 할인 이력이 필요해졌기 때문에 반환 값을 할인 이력 value object 리스트와 최종 할인 값을 담은 객체로 바꿨습니다. 
- 어떤 할인이 먼저 적용되면 다른 할인을 쓰지 못하도록 구현하는 내용은 담지 못하였지만, 보통 고정 값 할인 이후 비율 할인이 적용되는 것을 구현했습니다.

## **3. 결제 리포지토리 기능 추가**

- 2의 계산 과정의 객체를 payment 도메인 객체에 담아 리포지토리에서 결제 성공 시 할인 이력으로 저장하도록 하였습니다. 
- 할인 이력 엔티티 객체와 할인 이력 도메인 객체의 상호 변환 로직도 구현했습니다.
