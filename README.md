# 기본 요구 사항 구현 시 중점으로 둔 것

## **1. ERD 설계**

- "할인 정책이 자주 바뀐다."라는 점에 집중해서 할인 설계를 어떻게 할지 집중했습니다.
- 그 결과 할인율을 따로, 그 할인율을 적용 받는 조건을 따로 만들어서 할인율을 바꿔도 할인 조건을 유지하거나 할인 조건을 할인율에 따라 마음대로 바꿀 수 있도록 하였습니다.

## **2. 영속성 계층과 서비스 로직(응용 계층)의 분리**

- 평소 서비스 로직에 JPA 엔티티 객체가 끼어드는 형태로 개발을 했었지만, 최근 DDD나 클린 아키텍처에 대해 관심이 생겼습니다.
- 그래서 서비스 로직에 JPA 엔티티 객체가 끼어드는 대신 순수한 자바 객체인 도메인 객체만 다루도록 하여 서비스 로직(응용 계층)과 영속성 계층을 분리하였습니다.
